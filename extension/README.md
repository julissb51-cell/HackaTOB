# extension

**Responsable:** Persona B

Extensión de Chrome (Manifest V3) para Enlaza. Lee lo que la persona escribe y recibe en ChatGPT y Gemini en la web. Deja ganchos listos para Cursor y Claude Code.

Envía esos eventos a la sala y pide el contexto al conectarse y cada 30 segundos.

`mock/context.json` es una respuesta falsa de `GET /api/rooms/:id/context?member=Ana`, para probar sin el servidor.
